# Project conventions

## Design

Use the `impeccable` skill for all design and frontend work on this site —
layout, visual hierarchy, typography, spacing, colour, motion, responsive
behaviour, accessibility and UX copy. Invoke it before writing component
markup or styles, not after, so the visual system is deliberate rather than
default-Tailwind.

This applies to new components, redesigns and polish passes alike. Content
and data-layer work (`src/content/`) does not need it.
